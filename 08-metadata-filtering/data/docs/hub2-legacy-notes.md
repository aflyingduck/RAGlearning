# Nimbus Hub 2 — Legacy Notes

The Hub 2 was discontinued when the Hub 3 launched in March 2025, but is
still supported. Several procedures and specs differ from the Hub 3 —
follow this document, not the general guides, if you have a Hub 2.

**Hub 2 factory reset.** Hold the pairing button for 10 seconds until the
status ring flashes orange, then release. (The Hub 3 uses 15 seconds and
flashes purple — using the Hub 3 timing on a Hub 2 will instead trigger a
network-stack restart partway through and not complete the reset.)

**Hub 2 device limit.** The Hub 2 supports up to 75 connected devices per
hub, compared to the Hub 3's 200. Hub 2 units cannot be added to a Hub
Mesh group with Hub 3 units — Hub Mesh requires all paired hubs to be the
same generation.

**Hub 2 hardware.** Single-core 800 MHz processor, 512 MB RAM, 4 GB
onboard storage. No Thread support (Wi-Fi and Zigbee only). Voice commands
are always processed locally; the Hub 2 does not support Enhanced Voice
Recognition or any cloud voice processing, regardless of subscription.

**Hub 2 warranty.** Original Hub 2 units are past their standard 2-year
warranty window as of 2025, but any unit purchased with Nimbus Care
extended warranty within its first 60 days is still covered through the
full 4-year term from its original purchase date.

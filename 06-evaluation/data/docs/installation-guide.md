# Nimbus Hub — Installation Guide

1. Plug the Hub into power using the included USB-C adapter. The status ring
   will pulse blue while it boots, which takes about 30 seconds.
2. Open the Nimbus app (iOS 15+ or Android 11+) and tap "Add Hub."
3. Hold the pairing button on the back of the Hub for 3 seconds until the
   status ring flashes white. This puts the Hub into pairing mode for 2
   minutes.
4. The app will detect the Hub over Bluetooth and walk you through joining
   your Wi-Fi network. The Hub only supports 2.4 GHz Wi-Fi for initial setup;
   it can use 5 GHz for normal operation after setup completes.
5. Once connected, the status ring turns solid green. If it turns red,
   see the Troubleshooting guide.

For Hub Mesh setups, install the primary Hub first, then repeat steps 1–5 for
each additional Hub. In the app, go to Settings > Hub Mesh > Add Hub to Mesh
to link them. Mesh linking requires all hubs to be on the same local network.

Placement matters: keep the Hub at least 30 cm from routers or microwaves to
avoid 2.4 GHz interference with Zigbee devices, which share that frequency
band.

# Nimbus Hub — Product Overview

The Nimbus Hub is a smart-home controller made by Solstice Labs. It connects to
Wi-Fi, Zigbee, and Thread devices from a single unit and coordinates them
through the Nimbus mobile app.

The current model is the Nimbus Hub 3, released in March 2025. It replaced the
Nimbus Hub 2, which is still supported but no longer sold. The Hub 3 has a
1.8 GHz quad-core processor, 2 GB of RAM, and 16 GB of onboard storage for
local automation scripts and cached voice models.

The Hub 3 supports up to 200 connected devices per hub. Larger homes can pair
multiple hubs together using Hub Mesh, which lets automations reference
devices on any paired hub as if they were local.

Power draw is 6 watts at idle and up to 11 watts during active voice
processing. The unit ships with a USB-C power adapter; no battery backup is
included, though an optional Nimbus Battery Base (sold separately) provides
up to 4 hours of runtime during a power outage.
